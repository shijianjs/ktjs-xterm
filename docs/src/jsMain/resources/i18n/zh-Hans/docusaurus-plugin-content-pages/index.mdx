<ktjs-features section-title="封装了什么" tinted>

<ktjs-feature icon="lucide:terminal" title="终端本体">`Terminal`、缓冲区、解析器钩子，以及全部十三个 `on*` 事件——按上游 `xterm.d.ts` 声明，没有 dynamic 调用。</ktjs-feature>

<ktjs-feature icon="lucide:maximize" title="五个 addon">`fit`、`search`、`serialize`、`unicode11`、`web-links`，各自来自独立 npm 包，通过 `loadAddon` 装载。</ktjs-feature>

<ktjs-feature icon="lucide:radio" title="事件即函数">上游 `IEvent<T>` 是可调用对象，这里是函数类型加 `listen` 扩展：订阅一行写完，返回自己的 disposer。</ktjs-feature>

<ktjs-feature icon="lucide:table" title="缓冲区有类型">`IBuffer` → `IBufferLine` → `IBufferCell` 无需强转就能走通，包括 `translateToString` 与逐格属性读取。</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="对真实库测试">模块测试跑在 Chromium 里、直连打包进来的 `@xterm/xterm`；demo 另有 Playwright 套件，会往真实终端里敲字。</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="双语文档">本站由 ktjs-docusaurus 构建：类型化配置、Markdown 页面、中英两版。</ktjs-feature>

</ktjs-features>
