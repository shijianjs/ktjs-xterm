<ktjs-features section-title="What it wraps" tinted>

<ktjs-feature icon="lucide:terminal" title="The terminal itself">`Terminal`, its buffers, the parser hooks and all thirteen `on*` events — declared from the upstream `xterm.d.ts`, no dynamic calls.</ktjs-feature>

<ktjs-feature icon="lucide:maximize" title="Five addons">`fit`, `search`, `serialize`, `unicode11` and `web-links`, each from its own npm package and loaded through `loadAddon`.</ktjs-feature>

<ktjs-feature icon="lucide:radio" title="Events as functions">Upstream `IEvent<T>` is a callable object; here it is a function type with a `listen` extension, so a subscription is one line and returns its disposer.</ktjs-feature>

<ktjs-feature icon="lucide:table" title="Buffers are typed">`IBuffer` → `IBufferLine` → `IBufferCell` is navigable without casts, including `translateToString` and the per-cell attribute readers.</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="Tested against the real library">The module's tests run in Chromium against the bundled `@xterm/xterm`; the demo has its own Playwright suite that types into a live terminal.</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="Docs in two languages">This site is a Kotlin/JS module built by ktjs-docusaurus: typed configuration, Markdown pages, English and Chinese.</ktjs-feature>

</ktjs-features>
