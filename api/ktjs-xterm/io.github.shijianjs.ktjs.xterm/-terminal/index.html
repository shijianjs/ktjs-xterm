Terminal

external class Terminal(options: ITerminalConstructorOptions? = definedExternally) : IDisposable

The terminal, as the @xterm/xterm module exports it.

The class is the only runtime export of the package; every type it mentions is declared in XtermTypes.kt. Events are modelled as functions (IEvent<T> is a callable object), see TerminalEvent there.
